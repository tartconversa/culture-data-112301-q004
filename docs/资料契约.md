# 文化旅游引流的增量测算与预约承接资料约定

以下记录全部为本地合成数据，业务名称、参与方及数量不对应真实企业。

日期使用公历，带Z的时间为UTC。缺失值使用JSON null，空列表表示已知集合为空。资料主键仅表示该来源记录身份，业务版本与原始对象字段另行保留。

日容量与保护区上限分别约束总人数和进入保护区人数。演练线路所有成员均进入所列场馆的保护区。
相同bus和日期表示共享同一趟接驳，路线bus_seats是该车次容量，不能按线路相加。
linked为false的调查只有本次匿名身份，不支持跨次去重。没有观测到行程关联不等于确认是不同游客。
已接受团体只允许group_requests列出的整条替代线路，人数不能自动缩减。关闭并不消除已经成立的退款或协商义务。

## sites

场馆与保护区的人流上限。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 场馆 |
| daily_capacity | int | 日总容量 |
| protected_limit | int | 保护区日上限 |
| region | str | 所在区域 |

## routes

线路是共同消耗场馆和接驳席位的产品。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 线路 |
| sites | list | 访问场馆 |
| bus | str | 接驳车次 |
| bus_seats | int | 接驳单日容量 |

## daily_panel

客源地到场馆日面板，计数为到访次数。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 面板行 |
| on | str | 到访日 |
| origin | str | 客源地 |
| site | str | 场馆 |
| visits | int | 观测到访次数 |
| ticket_capacity | int | 票务容量 |
| sold_out | bool | 售罄标志 |
| rain_mm | float | 降雨毫米 |
| holiday | bool | 假日标志 |
| closed | bool | 关闭标志 |
| survey_coverage | float | 行程调查覆盖率 |

直接引用关系为site → sites.id。

## campaigns

分期推广与可能产生外溢的客源联系。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 推广 |
| origin | str | 主客源地 |
| start | str | 推广起日 |
| routes | list | 推广线路 |
| spillover_origins | list | 资料确认的外溢客源联系 |
| intensity | float | 推广投入相对量 |

## itinerary_survey

匿名抽样行程，一人同日可跨馆。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 调查记录 |
| person | str | 匿名人 |
| on | str | 到访日 |
| origin | str | 客源地 |
| sites | list | 同程场馆 |
| inclusion_probability | float | 调查纳入概率 |
| linked | bool | 是否允许稳定行程关联 |

## supply

未来供给，包括已售散客与接驳占用。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 供给行 |
| on | str | 日期 |
| site | str | 场馆 |
| sold_individual | int | 已售散客人数 |
| reserved_groups | int | 其他已确认团体人数 |
| bus_reserved | int | 已占接驳席位 |
| closed | bool | 是否关闭 |

直接引用关系为site → sites.id。

## group_requests

旅行社提出的整团候选。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 团体请求 |
| agency | str | 旅行社 |
| on | str | 到访日 |
| origin | str | 客源地 |
| route | str | 请求线路 |
| people | int | 人数 |
| expires_at | str | 报价失效时点 |
| allowed_substitutes | list | 整团接受范围内的替代线路 |

直接引用关系为route → routes.id。

## obligations

已经成立的团体权益。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 承诺 |
| group | str | 团体 |
| accepted_on | str | 接受日 |
| route | str | 已确认线路 |
| state | str | 承诺状态 |

直接引用关系为group → group_requests.id、route → routes.id。

## later_events

可后续到达的关闭及实际核销。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| id | str | 后续事实 |
| kind | str | closure关闭、redeem入馆、transport接驳 |
| on | str | 发生日 |
| site | str | 场馆 |
| group | str / null | 相关团体 |
| actual_people | int / null | 实际人数，非人数事件为空 |

直接引用关系为site → sites.id、group → group_requests.id。
